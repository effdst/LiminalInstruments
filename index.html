how it works

01 · BROWSER AS A STUDIO

No installations, no VSTs, no accounts. Each instrument is a single HTML file powered by the Web Audio API. Works locally, from a USB drive, on a phone, offline.

02 · INSTRUMENT, NOT A PLUGIN

Fixed frame, draggable knobs with Shift-precision, parameter locks, scenes, and ⚄ block randomization. The interface behaves like hardware, not a web form.

03 · RECORD & SHARE

Render to WAV, export patches to JSON, save banks in localStorage. Save a session, share the link, and someone else will hear the exact same thing.
